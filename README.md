# 网申速填 Plus

基于原网申速填另建的新项目。保留通用引擎，对 zhaopin.com 智联网申增加定向修正。当前为 **1.1.9**，已在用户目标智联页面验证新增教育表单的一次填入。

## 安装（Microsoft Edge）

1. 在旧插件资料库导出 JSON 备份。新插件与旧插件的存储相互独立。
2. 打开 `edge://extensions`，暂时关闭旧的网申速填；测试时也关闭其他填表插件，避免冲突。
3. 开启开发人员模式，选择“加载解压缩的扩展”，选择本项目文件夹（包含 manifest.json 的目录）。
4. 打开新插件的资料库，导入自己的 JSON 或原有三列表格 Excel。内置数据为空，不会自动补充个人资料。
5. 保存资料后刷新招聘页面，点击“一键填入”。智联会填写当前已展开的各类经历；北森保持原基础/增强模式。
6. 遇到折叠、未添加的经历，先在网页手动添加/展开，再填入。每条记录的“添加/保存”由本人检查后操作。

插件不会点击“立即投递”。填写后核对所有字段，特别是学校、学历、日期、经历顺序及下拉候选。

## 此次修正

- 智联优先识别单个字段容器内的标签，减少双列布局串位。
- 智联一键填入包含当前展开的实习、项目等，不再仅限基本资料和第一条教育。
- 智联禁用失败下拉的跨字段类型反推，避免将教育类型写到学校等字段。
- 保留透明代理输入框对应的自研下拉，支持“全日制统分统招”别名。
- 智联写入后等待延时校验，清空的文本不计作成功。
- 不自动合并默认简历；诊断不复制原始表单 HTML 或 URL 查询参数。

## 测试及限制

`npm ci` 后运行 `npm test`。自动测试模板使用 Node.js 26。32 项字段与数据检查、7 项组件交互检查、1 项并发检查、8 项家庭检查、11 项 Hotjob 检查；合成 DOM 检查涵盖学校串位、院系专业、经历范围、北森域通用填写、候选选中、自研下拉、日期、缺失资料、隐藏字段、延时清空以及不提交。

这些检查不代表北森或智联所有版本均已通过。已读取目标真实页面 DOM 并补充复现测试；已在目标智联页面，从新增的空白教育表单验证一次填入：学校精确选择候选、院系专业课程、学历学位、日期、排名、海外经历及辅导员证明人；没有保存记录或提交投递。家庭情况已在真实空白表单验证一次填入姓名、关系、单位与职务。其他模块和站点仍需逐项验收。学校搜索接口、跨域 iframe、上传、级联地区和未展开的记录仍需现场检查。下一步请在目标页面运行“填写记录 → 建议反馈 → 复制诊断”（以实际面板名称为准）提供字段映射；分享前检查文本。诊断仅本地复制，不自动上传。

## 隐私

简历保存在该扩展的浏览器本地存储，不包含云端简历接口。填入招聘页面时，页面可能自动保存到招聘网站。仓库和安装包均不包含个人简历或 GitHub 凭据。不要将个人 JSON、诊断原文或凭据提交到仓库。

## 版本维护

main 为维护分支；每次修改提交代码并运行测试，更新 manifest/package 版本，打 v 开头标签。自动测试模板位于 maintenance/github-actions-test.yml；当前凭据不具备 workflow 权限，未启用 GitHub Actions。如需启用，请在 GitHub 网页将模板放入 .github/workflows/test.yml。Release 的 zip 为可加载的扩展文件，解压后安装。问题反馈请提供域名、字段标签和预期行为，避免身份证、手机号等个人内容。

原引擎及 Excel 导入功能继承自用户提供项目；vendor/xlsx.full.min.js 的第三方许可见 THIRD_PARTY_NOTICES.md。
